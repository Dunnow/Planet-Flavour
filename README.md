# Planet Flavour

A flavour and content mod for [Stellaris](https://store.steampowered.com/app/281990) that adds depth and variety to planets, colonisation, and early-game exploration.

[![Steam Workshop](https://img.shields.io/badge/Steam_Workshop-Subscribe-1b2838?logo=steam)](https://steamcommunity.com/sharedfiles/filedetails/?id=3599349985)
[![Discord](https://img.shields.io/badge/Discord-Modding_Den-5865F2?logo=discord&logoColor=white)](https://discord.gg/bHVez2C)

**Stellaris compatibility:** 4.4.\*

---

## Features

### Planetary
- 100+ new planet modifiers
- 30+ new blockers and deposits
- Unique zones and planet-specific decisions

### Events
- Dozens of new colony events
- New exploration events
- Reactive terraforming events designed to preserve flavour and immersion

### Exploration
- Several new unique systems and event chains
- New anomalies and special projects

## Installation

### From the Steam Workshop (recommended)
[Subscribe on the Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3599349985) — the mod will download automatically and appear in your Stellaris launcher.

### From source
If you'd rather install manually (e.g. to run a development version), clone or download this repository into your Stellaris `mod` folder:

| OS      | Path                                                           |
|---------|----------------------------------------------------------------|
| Windows | `%USERPROFILE%\Documents\Paradox Interactive\Stellaris\mod\`   |
| macOS   | `~/Documents/Paradox Interactive/Stellaris/mod/`               |
| Linux   | `~/.local/share/Paradox Interactive/Stellaris/mod/`            |

You will also need a `.mod` descriptor file in the `mod/` folder pointing at the cloned directory. Then enable **Planet Flavour** in the launcher's Mods tab.

> **A new game is strongly recommended for the best experience.**

## Compatibility

This mod **does not overwrite any vanilla files.**

| Mod                          | Status                                                                 |
|------------------------------|------------------------------------------------------------------------|
| Guilli's Planet Modifiers    | Compatible (some thematic duplication may occur)                       |
| Planetary Diversity          | Compatible — minor bugs possible, please report any you encounter      |
| Real Space                   | Compatible — minor bugs possible, please report any you encounter      |
| The Blocker Mod              | Fully compatible                                                       |

If you find a conflict not listed here, please open an issue or report it on the Workshop page.

## Reporting bugs and contributing

- **Bugs / suggestions:** open an [issue](../../issues) here, or post on the [Workshop comments](https://steamcommunity.com/sharedfiles/filedetails/?id=3599349985) / [Discussions](https://steamcommunity.com/sharedfiles/filedetails/discussions/3599349985)
- **Discussion:** join the [Modding Den Discord](https://discord.gg/bHVez2C)
- **Pull requests:** welcome — please describe what your change does and why. For larger content additions, consider opening an issue first to check it fits the mod's direction.

When reporting a bug, it helps a lot to include:
- The Stellaris version
- A list of other mods you're running (load order matters)
- Steps to reproduce, and a save file if possible
